# Student Performance Prediction

## Goal
Predict student final marks using academic features.

## Features
- Study Hours
- Attendance
- Previous Marks

## Target
- Final Marks

## Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Machine Learning Workflow

1. Load dataset
2. Separate features and target
3. Split data into training and testing sets
4. Train Linear Regression model
5. Generate predictions
6. Evaluate the model

## Model

Model used:
Linear Regression

## Evaluation Metrics

- MAE
- MSE
- RMSE
- R² Score
